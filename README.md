# Habit Tracker

A habit tracker built with Angular. Habits, completions, and settings are saved in `data/tracker.json` inside this project. Copy the project folder to another laptop and the same data comes with it.

## Run

```bash
npm start
```

Open `http://127.0.0.1:4200`.

`npm start` runs the app and a small local file server. The file server only writes `data/tracker.json`. Data is not kept in server memory.

## Scripts

- `npm start` — app and data file server
- `npm run build` — production build
